# Market-Stack SDK

Official HTTP client libraries for Alpha API (`/v1`) using API key authentication (`X-API-Key`).

| Language   | Directory | Package name      |
|-----------|-----------|-------------------|
| Python    | `python/` | `market-stack-sdk` on PyPI (import `market_stack_sdk`) |
| TypeScript | `js/`    | `@manasija/market-stack-sdk` on npm |

See `python/README.md` and `js/README.md` for install and usage.

## Agent Skill

This repository includes a Drishti SDK skill for coding agents under
`skills/drishti-sdk/`.

Install it with:

```bash
npx skills add manasijatech/Market-Stack-SDK
```
