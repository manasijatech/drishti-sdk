The official Java client for the Drishti Indian stock-market API (/v1). It covers corporate announcements, earnings filings, conference calls, news, block deals, market alerts, AI daily summaries, batch jobs and live websocket streams.

Requirements

  • Java 17 or later.
  • A Drishti API key from the platform console.
  • One runtime dependency, Jackson Databind. HTTP and websockets use the JDK's java.net.http.

Install

<dependency>
  <groupId>in.manasija</groupId>
  <artifactId>drishti-sdk</artifactId>
  <version>1.0.0</version>
</dependency>

Quick start

{@code
DrishtiClient client = DrishtiClient.create(System.getenv("DRISHTI_API_KEY"));

JsonNode news = client.getNews(new NewsParams().symbols("RELIANCE", "TCS").limit(10));
for (JsonNode item : news.path("data")) {
    System.out.println(item.path("symbol").asText() + ": " + item.path("title").asText());
}
}

Live streams

{@code
DrishtiWebSocketSession ws = client.websocket()
        .onAnnouncements(a -> System.out.println(a.path("symbol").asText() + " " + a.path("summary").asText()))
        .onSubscribed(ack -> System.out.println("subscribed on tier " + ack.tier()));
ws.subscribe("announcements", List.of("RELIANCE", "TCS"));
ws.run(); // reconnects and resubscribes automatically until stop()
}

Batch summaries

{@code
String jsonl = Params.buildBatchInputJsonl(List.of(
        Map.of("custom_id", "tcs", "symbols", List.of("TCS"), "mode", "news_context"),
        Map.of("custom_id", "infy", "symbols", List.of("INFY"), "mode", "news_context")));
JsonNode job = client.submitBatchJobAndWait(new BatchJobRequest("watchlist.jsonl", jsonl),
        Duration.ofSeconds(5), Duration.ofMinutes(30));
List results = client.getBatchJobsJobIdResultsParsed(job.path("id").asText());
}

Behaviour shared by every Drishti SDK

This SDK passes the same cross-language conformance suite as the Python, TypeScript and PHP SDKs. Requests, retries, error handling and websocket parsing therefore behave the same in every language.
